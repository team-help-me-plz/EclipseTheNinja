# 간단한 마우스 입력 이미지

내장 image_gen으로 승인된 마우스 샘플에서 변형한 투명 배경 PNG 5종이다. 원본은 글자 없이 마우스 외곽과 버튼 구분선을 흰색으로 표시하고, 누르는 부위만 흰색으로 채운다. 몸통 내부는 회색으로 채운다.

| 파일 | 흰색 강조 부위 |
| --- | --- |
| LeftMouseButton.png | 왼쪽 클릭 버튼 |
| RightMouseButton.png | 오른쪽 클릭 버튼 |
| MiddleMouseButton.png | 가운데 휠 클릭 |
| ThumbMouseButton.png | 왼쪽 측면 아래 버튼 4, 뒤로 |
| ThumbMouseButton2.png | 왼쪽 측면 위 버튼 5, 앞으로 |

## 제작 지시

공통 지시는 승인된 마우스의 세로 모양, 크기, 위치, 흰색 외곽선과 버튼 구분선을 유지하고, 해당 버튼만 흰색으로 강조하는 것이다. 불필요한 글자, 화살표, 질감과 입체 묘사는 줄인다. 몸통 내부는 구멍 없이 불투명한 회색으로 채우고 외부에만 투명 배경을 사용한다.

왼쪽 클릭은 승인된 구멍 보정 샘플을 사용한다. 오른쪽 클릭은 왼쪽 버튼을 회색으로 돌리고 오른쪽 버튼을 흰색으로 채운다. 휠 클릭은 두 기본 버튼을 회색으로 두고 휠만 흰색으로 채운다. 추가 버튼은 왼쪽 측면에 두 개의 작은 캡슐 모양 버튼을 배치하고 아래쪽 버튼 4 또는 위쪽 버튼 5만 흰색으로 채운다.
